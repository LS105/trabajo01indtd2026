# Trabajo individual 1 - Teoría de la Decisión

**Autor/a:** Lucía Sánchez García  
**Asignatura:** Teoría de la Decisión  

## Descripción

Este repositorio contiene el trabajo individual sobre métodos de decisión bajo incertidumbre, realizado mediante R, RStudio y Quarto.

Se plantean dos problemas originales:

- **Problema 1:** estudio de una tabla de decisión con valores inventados, aplicando por separado los criterios de Wald, Optimista, Hurwicz, Savage, Laplace y Punto Ideal, tanto en situación favorable como desfavorable.
- **Problema 2:** decisión sobre la posición ofensiva de un jugador de fútbol, teniendo en cuenta distintos planteamientos del equipo rival. Se resuelve utilizando la función `criterio.Todos()`.

Cada problema incluye cinco afirmaciones de verdadero o falso, cuyas respuestas se justifican en el documento de soluciones.

## Contenido del repositorio

- `enunciados.qmd`: enunciados de los dos problemas.
- `soluciones.qmd`: resolución e interpretación de los resultados.
- `enunciados.html` y `soluciones.html`: documentos generados en HTML.
- `enunciados.pdf` y `soluciones.pdf`: documentos PDF generados mediante Typst.
- `teoriadecision_funciones_incertidumbre.R`: funciones R proporcionadas en la asignatura.

## Herramientas utilizadas

Se ha utilizado RStudio para el desarrollo del proyecto, Quarto para elaborar los documentos, las funciones R de la asignatura para resolver los problemas y GitHub para el control de versiones.

Los documentos pueden reproducirse desde los archivos `.qmd`, utilizando las funciones R incluidas en el repositorio.
